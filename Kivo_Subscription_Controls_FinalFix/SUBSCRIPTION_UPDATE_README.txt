KIVO SUBSCRIPTION CONTROLS UPDATE

NEW CONTROLS
- Paid: advances a recurring subscription one billing cycle.
- Back one cycle: moves it backwards one billing cycle. This also works on old subscriptions
  that were accidentally advanced before payment-history tracking existed.
- Cancel: stops/cancels the item without deleting it.
- Reactivate: turns a cancelled item back on.
- Remove: permanently deletes the item from Kivo.

INSTALL
1. Close every Kivo server/CMD window.
2. Extract this ZIP directly into your EXISTING Kivo folder.
3. Choose Replace files when Windows asks.
4. Run start-kivo.bat again.

This update ZIP does NOT contain data/kivo.db, so it will not overwrite your users or saved items.
